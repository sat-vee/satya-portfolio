# Satya Singh — AI/ML Portfolio

A Next.js portfolio starter for Satya Singh, positioned around AI/ML engineering, GenAI, Agentic AI and solution architecture.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Push this repository to GitHub and import it into Vercel. The project is intentionally simple so case studies, architecture pages and insights can be added without restructuring the site.
